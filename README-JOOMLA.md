    --ids-green: #145a3a;        /* Your brand color here */

## 🆘 Common Issues & Solutions

### Issue: CSS Not Working
**Fix:**
1. Clear Joomla cache
2. Hard refresh browser (Ctrl+F5)
3. Check CSS pasted correctly

### Issue: Images Missing
**Fix:**
1. Upload images to Joomla Media Manager
2. Update paths in HTML to match

### Issue: Links Broken
**Fix:**
1. Verify `/contact` page exists
2. Update URLs to match your site structure

### Issue: Mobile Layout Broken
**Fix:**
1. Ensure mobile CSS included
2. Check viewport meta tag in template
3. Test with real device
