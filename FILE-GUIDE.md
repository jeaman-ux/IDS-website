## 📦 ESSENTIAL FILES (Required)

### joomla-content.html
**What:** The page HTML content
**Size:** 30KB
**Action:** Copy entire file → Paste into Joomla article (Code view)
**Note:** This is the main page content without header/footer

### assets/css/sustainability-recycling.css
**What:** All page styling
**Size:** 33KB
**Action:** Copy entire file → Paste into Template Custom CSS
**Note:** Includes CSS variables for easy customization

### assets/images/hero-dumpster.png
**What:** Hero section image
**Size:** 4.1MB
**Action:** Upload to Joomla Media Manager
**Note:** Consider compressing to < 200KB for faster loading
