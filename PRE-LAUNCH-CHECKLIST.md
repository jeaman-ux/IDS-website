# Pre-Launch Checklist
## Sustainability & Recycling Page

Use this checklist before publishing your page.

---

## 📝 Content Review

- [ ] All text is accurate and approved
- [ ] Company name "IDS" appears correctly throughout
- [ ] "Broad Run Recycling" is spelled correctly
- [ ] All statistics are current (700+ Tons Daily, etc.)
- [ ] No placeholder text remains (lorem ipsum, etc.)
- [ ] Headings make sense and are grammatically correct
- [ ] No typos or spelling errors

---

## 🔗 Links Testing

### Internal Links
- [ ] "See How IDS Supports Sustainability" scrolls to section
- [ ] "Talk to IDS" goes to correct contact page
- [ ] "Contact IDS to Get Started" goes to contact page
- [ ] "Mitigate Risk. Get Accurate Reporting" goes to contact page
- [ ] All `/contact` links work

### External Links
- [ ] Broad Run main site opens in new tab
- [ ] Broad Run materials page opens in new tab
- [ ] All external links have `rel="noopener noreferrer"`
- [ ] No broken links (404 errors)

---

## 🎨 Design & Styling

### Colors
- [ ] Green accent color matches brand (#145a3a)
- [ ] Text is readable (good contrast)
- [ ] Hover states work on buttons
- [ ] Links change color on hover

### Layout
- [ ] Hero section displays correctly
- [ ] All 5 sections are visible
- [ ] Comparison card displays properly
- [ ] Callout section is centered
- [ ] No overlapping elements
- [ ] Proper spacing between sections

### Typography
- [ ] Roboto font loads correctly
- [ ] Headings are proper sizes
- [ ] Text is readable at all sizes
- [ ] No text overflow or cut-off

---

## 📱 Responsive Testing

### Mobile (< 768px)
- [ ] Test on actual iPhone
- [ ] Test on actual Android phone
- [ ] Hero section stacks correctly
- [ ] Buttons are full width
- [ ] Text is readable without zooming
- [ ] No horizontal scrolling
- [ ] Comparison columns stack vertically
- [ ] Images scale properly

### Tablet (768px - 991px)
- [ ] Test on iPad or similar
- [ ] Layout adapts properly
- [ ] Text remains readable
- [ ] Buttons are appropriately sized

### Desktop (> 992px)
- [ ] Test on 1920px width
- [ ] Test on 1366px width
- [ ] Content is centered
- [ ] Images display at proper size
- [ ] Two-column layouts display correctly

---

## ⚡ Performance

- [ ] Page loads in < 3 seconds
- [ ] Images are optimized (< 200KB each)
- [ ] No console errors (F12 → Console tab)
- [ ] Smooth scroll animation works
- [ ] No layout shift on page load
- [ ] CSS loads without delay

---

## ♿ Accessibility

- [ ] Can navigate with keyboard only (Tab key)
- [ ] All images have alt text
- [ ] Buttons have descriptive text
- [ ] Heading hierarchy is correct (H1 → H2 → H3)
- [ ] Color contrast meets WCAG standards
- [ ] Links are clearly identifiable

---

## 🌐 Browser Testing

- [ ] Chrome (latest version)
- [ ] Firefox (latest version)
- [ ] Safari (Mac/iOS)
- [ ] Edge (latest version)
- [ ] Mobile Safari (iOS)
- [ ] Chrome Mobile (Android)

---

## 🔍 SEO & Meta

- [ ] Page title is set (in Joomla article)
- [ ] Meta description is added
- [ ] URL alias is `sustainability-recycling`
- [ ] Page is set to "Published"
- [ ] Category is selected
- [ ] Sitemap includes new page
- [ ] robots.txt allows indexing

---

## 📊 Analytics

- [ ] Google Analytics tracking code is active
- [ ] Event tracking on CTA buttons (optional)
- [ ] Conversion goals set up (optional)
- [ ] Page view tracking works

---

## 🔒 Security

- [ ] All external links use https://
- [ ] External links have `rel="noopener noreferrer"`
- [ ] No inline JavaScript with security issues
- [ ] No embedded third-party scripts
- [ ] Forms use proper validation (if any)

---

## 💾 Backup & Safety

- [ ] Full site backup created before deployment
- [ ] Database backup created
- [ ] Can rollback if needed
- [ ] Staging site tested first (if available)

---

## 📢 Launch Day

- [ ] Clear all caches (Joomla, browser, CDN)
- [ ] Test one final time after clearing cache
- [ ] Notify team that page is live
- [ ] Monitor for 24 hours after launch
- [ ] Check analytics for traffic
- [ ] Watch for error reports

---

## ✅ Post-Launch (Week 1)

- [ ] Check analytics daily
- [ ] Monitor for broken links
- [ ] Review user feedback
- [ ] Check mobile performance on real devices
- [ ] Verify search engines are indexing
- [ ] Test all forms and CTAs again

---

## 🎉 All Done!

If all boxes are checked, you're ready to launch!
