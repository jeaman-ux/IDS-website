# IDS Website - Sustainability and Recycling Page

**Project Date:** January 26, 2026
**Page URL:** `/sustainability-recycling`
**Status:** Design Ready for Implementation

## Project Overview

This package contains the complete design specifications and HTML/CSS structure for a new Sustainability and Recycling page for the IDS Waste website. The page is designed to provide proof of IDS's sustainability and recycling process while giving visitors clear options to learn more or contact sales.

## Package Contents

```
sustainability-recycling-page/
├── README.md                           # This file - project overview and guide
├── IMPLEMENTATION-NOTES.md             # Technical implementation instructions
├── sustainability-recycling.html       # Complete HTML page structure
└── assets/
    └── css/
        └── sustainability-recycling.css # Page-specific styles
```

## Page Goal

Provide proof of IDS's sustainability and recycling process while giving visitors a clear option to either learn more or skip directly to sales contact.

## Page Sections

1. **Hero Section** - "Recycling You Can Prove"
2. **Section A** - Sustainability You Can Stand Behind
3. **Section B** - Broad Run Recycling (includes tab and accordion module)
4. **Section C** - Why Accurate Reporting Matters (includes comparison accordion)
5. **Final Conversion CTA** - Bottom page conversion block

## Technology Stack

- **CMS:** Joomla (current version on idswaste.com)
- **Template:** Shaper HelixUltimate
- **HTML:** Semantic HTML5
- **CSS:** Responsive, mobile-first approach
- **Breakpoints:**
  - Desktop: 992px and up
  - Tablet: 768px to 991px
  - Mobile: 767px and below

## Key Design Elements

- **Typography:** Roboto font family (matching existing site)
- **Primary Color:** #145a3a (IDS green for links and accents)
- **Interactive Elements:** Accordion and tab module in Section B
- **CTAs:** Multiple strategic calls-to-action throughout the page
